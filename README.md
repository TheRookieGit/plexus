# Plexus

和本地 Plex 同步的影视收藏系统：把 Plex 收录的、硬盘上实际存在的、网盘里还没下载的影视放在同一个目录里，交叉对比找出问题；粘贴夸克 / 百度网盘链接就能下载到选定的盘，按 Plex 推荐格式命名；在 Plexus 里删除会直接删掉硬盘上的文件。

## 从源码启动

双击 **启动 Plexus.bat**，浏览器会打开 <http://127.0.0.1:8766>。需要 Python 3.10 或更新版本，不需要安装其他包。数据保存在项目的 `.data` 文件夹。

```powershell
python server.py
python server.py --port 8767 --no-browser
python -m unittest discover -s tests -t .   # 运行测试
```

Plex 的登录信息自动从这台电脑上的 Plex Media Server 读取。启动后立即同步一次，之后每 5 分钟同步一次，也可以点顶栏的「同步」。

## 运行方式

沿用 [书屿](https://github.com/TheRookieGit/shuyu) 的结构：

- **Windows 后台常开**：Python 标准库服务，托盘运行、开机自启、自动更新。负责连接 Plex、扫描硬盘、网盘下载和删除文件。
- **网页版（GitHub Pages）**：任何设备打开同一个界面，数据只存在 Windows 电脑上，所以各端天然同步。经 Tailscale Funnel 等 HTTPS 隧道连回后台，需要访问密码。
- Windows 本机直接访问不需要密码。

## 1. 和 Plex 同步（单向：Plex → Plexus）

- 自动读取本机 Plex Media Server 的 token 和媒体库，不需要另外登录。
- 从 Plex 读入每部影片 / 剧集的标题、年份、海报、简介、清晰度、文件路径。
- Plexus 不改 Plex 的元数据。只在两种情况下通知 Plex：下载完成后扫描对应文件夹，删除后刷新并清空 Plex 回收站。
- Plex 库里已经不存在的路径（如已停用的 Y 盘）直接忽略，不算作"文件丢失"。

## 2. 收藏目录

- **我拥有的**：Plex 收录的 + 硬盘上有但 Plex 没收录的，合成一个总目录。
- **想看 / 收藏**：标记想看的影视，可以记下网盘链接，以后一键下载。

## 3. 交叉对比

- 硬盘上有、Plex 没收录或匹配错误
- Plex 里有、文件已不存在
- 同一部片在多个盘各有一份（重复）
- 同一部片的多个版本（4K / 1080p 等），帮助决定保留哪个

## 4. 目录树

参考书屿的「文件夹」：按盘和子文件夹逐层展开，每一行显示其中影片 / 剧集的数量（包括更深的子文件夹），点开可以继续往下，点条目进入详情。

## 5. 网盘下载

- 支持夸克网盘和百度网盘的分享链接（可带提取码，一次可贴多个）。登录、转存和下载沿用书屿 `netdisk.py` 的做法，改为接收视频和字幕。
- 每次下载前选择放到哪个盘 / 哪个库。
- 下载完成后按 Plex 推荐格式给出重命名方案，**确认后才重命名**：
  - 电影：`电影名 (年份)/电影名 (年份).mkv`
  - 剧集：`剧名 (年份)/Season 01/剧名 (年份) - S01E01.mkv`
- **下载队列**，支持**断点续传**；断电或重启后自动接着下载。
- 有单独的**下载页面**，显示每个任务的进度、速度、剩余时间，可以暂停、继续、取消。

## 6. 删除

- 在 Plexus 里删除会直接删掉硬盘上的实际文件，**整个文件夹一起删**（含字幕、nfo、海报）。
- E 盘和 Z 盘（NAS）都是直接删除，不进回收站，所以会弹出**二次确认**，列出将要删除的路径和大小。
- 剧集每次可以选择删除单集、整季或整部。
- 删除后通知 Plex 刷新并清空回收站。
