# Plexus

和本地 Plex 同步的影视收藏：把 Plex 收录的和硬盘上实际存在的影视放在同一个目录里，交叉对比找出没收录、丢失和重复的文件；粘贴夸克 / 百度网盘链接就能下载到选定的盘，确认后按 Plex 推荐格式命名；在 Plexus 里删除会直接删掉硬盘上的文件。

## Windows 应用

从 [Releases → Plexus Windows 版（最新）](https://github.com/TheRookieGit/plexus/releases/tag/app-latest) 下载 `Plexus-windows.zip`，解压到桌面、文档等自己可以写入的位置，双击 **Plexus.exe**。不需要安装 Python。

- Plexus 在独立的应用窗口中打开（Windows 自带的 Edge 应用模式）。关闭窗口不会停止 Plexus：它在右下角托盘继续运行，下载不会中断，网页版也能连接。双击托盘图标重新打开；要完全停止，在托盘右键菜单选「退出」。
- 托盘菜单可以勾选 **开机自动启动**，开机后只在托盘中运行。
- **自动更新**：启动时和之后每 10 分钟检查 GitHub 上的最新构建，发现新版后自动下载、替换并重启。正在转存或正在把下载放入媒体库时会等它完成；正在下载时最多等 2 小时，更新后下载会从断点继续。
- 数据保存在 `%LOCALAPPDATA%\Plexus`。**从源码版迁移**：先关闭源码版，把项目 `.data` 文件夹里的全部内容复制到 `%LOCALAPPDATA%\Plexus`，再启动应用；访问密码、网盘登录、收藏和想看都会保留。

每次推送到 `main`，`.github/workflows/windows-app.yml` 会在 Windows 上运行测试、打包、试启动打包后的程序，更新这个 Release，并用一份旧版副本验证自动更新。

## 从源码启动

双击 **启动 Plexus.bat**，浏览器会打开 <http://127.0.0.1:8766>。需要 Python 3.10 或更新版本，不需要安装其他包。数据保存在项目的 `.data` 文件夹。

网盘相关的代码和书屿共用，放在 [my-collections](https://github.com/TheRookieGit/my-collections) 仓库的 `collectionkit` 里，作为 git submodule 放在 `vendor/my-collections`。clone 时要加 `--recursive`；已经 clone 过的，在项目文件夹里运行一次 `git submodule update --init`（缺了这部分，启动 .bat 会提示）：

```powershell
git clone --recursive https://github.com/TheRookieGit/plexus.git
```

```powershell
python server.py
python server.py --port 8767 --no-browser
python server.py --allow-origin https://therookiegit.github.io   # 允许网页版连接（启动 .bat 默认带此参数）
python -m unittest discover -s tests -t .                        # 运行测试
```

## 和 Plex 同步

- Plex 的登录信息自动从这台电脑上的 Plex Media Server 读取，不需要填写。启动时同步一次，之后每 5 分钟一次，也可以点顶栏的「同步」。
- 同步是单向的：Plexus 读取 Plex 的片名、年份、海报、简介、清晰度和每个文件的路径，不修改 Plex 的资料。只有两种情况会通知 Plex：下载放入媒体库后扫描那个文件夹；删除文件后扫描并清空 Plex 的回收站。
- 同时扫描 Plex 每个媒体库文件夹里的视频和字幕，和 Plex 记录的文件逐个比对。macOS 的 `._` 隐藏文件、NAS 的 `@eaDir`、`#recycle` 等会跳过。没有连接的盘不会被当成文件丢失。

## 影视目录

- 首页是所有影视的海报墙，可以按媒体库、硬盘筛选，按最近添加、片名、年份、占用空间排序，也可以搜索片名、原名或文件夹名。
- 点开一部影视：简介、评分、分季分集、每个文件的清晰度、编码、时长、大小和所在硬盘，可以「在 Plex 中打开」；在 Windows 本机上还能在资源管理器中定位文件。
- 顶部的提示会列出交叉对比发现的问题，点一下就筛出来：
  - **Plex 未收录**：硬盘上有、Plex 没有收录的视频。放在某部剧文件夹里的算进那部剧，其余的从文件夹名推测片名，单独成为一个条目。
  - **文件丢失**：Plex 里有、硬盘上已经找不到的文件。
  - **重复与多版本**：同一部电影或同一集有多份文件（例如 E 盘和 Z 盘各一份、1080p 和 4K 各一份），或者同一部影视在两个媒体库里各有一个条目。会显示只留一份可以释放多少空间，标「重复」的文件可以单独删除。
- **目录树**：按盘和文件夹逐层展开，每一行显示其中有多少视频、占多少空间、有几个 Plex 没有收录，点文件可以打开它所属的影视。

## 删除

- 在影视详情里点 **删除…**。电影直接删除整部；剧集可以选择删除 **整部、某一季或某一集**。每个文件右边的删除按钮只删除那一个文件（例如重复的版本）。
- **整个文件夹一起删**：一个文件夹里的视频全部属于要删除的内容时，整个文件夹连同字幕、海报、nfo 一起删除；文件夹里还有别的影视时，只删除这部影视的视频和同名的字幕、海报等文件。永远不会删除 Plex 媒体库文件夹本身。
- 删除前会列出每一个要删除的文件夹和文件、文件数和大小；确认后还有第二次确认，按钮 3 秒后才能点。E 盘和 Z 盘（NAS）都是直接删除，不进回收站，无法恢复。
- 删除后 Plexus 会通知 Plex 扫描并清空它的回收站，目录随之更新。所有删除都记录在数据库里。

## 网盘下载

顶栏的 **下载** 打开下载页面。

1. 第一次使用某个网盘时，在右上角点 **扫码登录**：夸克用夸克 App 扫，百度用百度网盘 App 扫，然后在手机上确认。登录信息加密保存在 Windows 电脑上（`%LOCALAPPDATA%\CollectionKit\netdisk.sqlite3`，不上传到任何地方）。**登录在 Plexus、书屿和心愿中枢之间共用**：在任意一处扫码登录，其他地方不用再扫；在任意一处退出，所有地方都会一起退出，所以退出要点两次确认。以前在 Plexus 里登录过的，升级后会自动沿用。
2. 粘贴夸克或百度网盘的分享链接（提取码可以一起粘贴，`?pwd=` 也行；一次可以粘贴多个链接），点 **读取链接**。每个分享列出里面的文件：视频和字幕默认勾选，图片、文档等其他文件不下载。
3. **选择放到哪个盘、哪个媒体库**（显示每个文件夹的剩余空间），点 **加入下载队列**。
4. 文件先转存到你自己网盘的 `Plexus转存` 文件夹，再下载到目标盘根目录下隐藏的 `.plexus-downloads` 文件夹（不在 Plex 媒体库里，Plex 不会提前扫描到半成品）。
5. 下载页面显示每个任务和每个文件的进度、速度和剩余时间，可以暂停、继续、取消（取消需要点两次）或重试。**断点续传**：网络中断、关闭 Plexus 或电脑重启后，会从已经下载的位置继续；出错会自动重试几次。网盘登录过期，或者在书屿里退出了网盘时，任务显示 **等待登录**，不会判为失败；在 Plexus 或书屿里重新扫码登录后，自动从断点继续。
6. 全部下载完后，任务变成 **等你确认名称**：Plexus 在 Plex 的在线资料库里查出可能的片名，列出每个文件将被改成的名字：
   - 电影：`片名 (年份)\片名 (年份).mkv`
   - 剧集：`片名 (年份)\Season 01\片名 (年份) - S01E01.mkv`
   - 字幕跟随对应的视频改名，保留 `.chs`、`.zh` 等语言标记。已经有这部剧的文件夹时，新的集会放进原来的文件夹。

   可以点另一个结果、修改片名、年份、类型或每一集的季号集号，点 **更新名称** 预览。确认后点 **按 Plex 格式重命名并放入媒体库**，或者 **保留原名放入**。放入后 Plex 会自动扫描这个文件夹。

想看清单里记下的网盘链接，可以在想看条目里点 **去下载**，链接会自动填进下载页面。

这是照着两个网盘网页版的做法实现的，不是官方接口；网盘改版后可能要更新 Plexus 才能继续使用。

## 收藏和想看

- 影视详情里点 **收藏**，筛选栏的「收藏」只显示收藏的影视。收藏跟着 Plex 对这部影视的识别走，换盘、换媒体库后仍然保留。
- 筛选栏的 **想看** 是还没有的影视：点「添加想看」，在 Plex 的在线资料库里搜索并选中（自动带海报、年份），记下网盘链接和备注。已经下载到媒体库的会标「已拥有」。
- **连接心愿中枢**（[我的心愿单](https://therookiegit.github.io/my-collections/) 网站）：在中枢的「设置 → 已配对的设备」里给 Plexus 生成配对码，粘贴到 Plexus「设置 → 心愿中枢」。连接后想看清单就是中枢里的电影和电视剧：在中枢记下的会出现在这里，在这里添加、修改、删除的也会同步到中枢（海报、简介和 Plex 的识别一起带上）；每次和 Plex 同步后，Plex 里有了的会在中枢标成「已拥有」，点「查看」直接打开 Plexus 网页版里的这部影视。在中枢点「不是这个」，Plexus 以后不会再把那部算作这条想看。第一次连接时，原来的想看清单会上传到中枢（片名和年份相同的不重复上传），原来的清单保留不动，断开连接后就回到它。连不上中枢时 Plexus 照常使用，要发送的内容等联网后补发。
- 中枢里的「送到 Plexus 下载」会打开下载页，链接已经填好并开始读取。

## 网页版（GitHub Pages）

网页版地址：<https://therookiegit.github.io/plexus/>。任何电脑、平板、手机都可以打开；网页只是界面，影视目录、下载和删除都在 Windows 电脑上进行，所有设备看到的是同一份数据。推送到 `main` 后 `.github/workflows/pages.yml` 自动发布。

一次性设置（Windows 电脑）：

1. 在本机打开 Plexus，**设置 → 网页版访问** 里设置访问密码，至少 6 个字符。
2. 给 Plexus 开一个固定的 HTTPS 地址。书屿已经占用了 Tailscale Funnel 的 443 端口，Plexus 用 8443：

   ```powershell
   tailscale funnel --bg --https=8443 8766
   ```

   网页版默认连接 `https://windows.tailc0b5f5.ts.net:8443`；地址不同时，可以在登录页点「更换后台地址」。
3. 在任意设备打开网页版，输入访问密码登录。每台设备只需登录一次，一年内用过会自动续期。

规则和书屿一样：Windows 本机直接访问不需要密码；经由隧道或网页版来的请求一律需要登录。修改 Plex 地址、设置访问密码、在资源管理器中定位文件只能在 Windows 电脑上操作；浏览、下载、删除在网页版也可以使用。连续输错 5 次密码会暂时锁定该来源。
